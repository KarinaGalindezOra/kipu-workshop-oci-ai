# Workshop 2: real OCI contract RAG with visible evidence

Use the canonical [participant guide](../../labs/lab02_contract_rag/README.md). Duration: 180 minutes, 15 participants, one Chicago tenant and ADB, individual identities/schemas and local dashboards. Each person reads their actual obtained answer beside expected criteria and inspects its source evidence.

The dashboard performs actual OCI embedding, ADB vector search and chat; there is no simulated/offline completion path. Version clarification and routing remain explicit application decisions. Follow the [dashboard operations](../../labs/lab02_contract_rag/docs/dashboard_operations.md), [individual isolation](../../labs/lab02_contract_rag/docs/participant_isolation.md), [facilitator runbook](../../labs/lab02_contract_rag/docs/facilitator_runbook.md) and [rubric](../../labs/lab02_contract_rag/docs/rubric.md).

Only synthetic disbursement documents are used. The reference matrix contains 16 cases without artificial provider/adversarial fixtures. Human review of the actual text remains required. Infrastructure, inference and load approvals must be completed before paid/mutating operations.
