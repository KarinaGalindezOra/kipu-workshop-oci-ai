# Actividades del participante — Workshop 2

Usa esta página junto con la [guía paso a paso](participant_step_by_step.md) y el [cuaderno de trabajo](participant_workbook.md). Las actividades se realizan desde tu estación de trabajo y dashboard local con contratos sintéticos.

| Actividad | Trabajo | Evidencia que debes registrar |
|---|---|---|
| Contrastar versiones | Lee v1 y v2 antes de consultar. | Tres cambios documentados. |
| Inspeccionar el corpus local | Ejecuta `run_local_practice.py inspect`. | Nueve fragmentos, versión, sección, líneas y hash. |
| Recuperación léxica local | Ejecuta T03 y T08 con `run_local_practice.py retrieve`. | Filtro de versión antes de ranking; evidencia de ambas versiones separada. |
| Preparar corpus | Ejecuta la carga OCI autorizada. | Nueve fragmentos en tu schema individual. |
| Responder con evidencia | Ejecuta T01 o T03. | Método, endpoint, cita y extracto. |
| Comparar sin contaminar | Ejecuta T08. | Una fuente v1 y otra v2, separadas. |
| Migrar con respaldo | Ejecuta T06. | Endpoint, campo y mapeos de estados con citas. |
| Reconocer límites | Revisa T05, T10 y T12. | Aclaración, abstención y decisión de datos estructurados. |
| Elegir RAG o SQL | Clasifica las preguntas del cuaderno. | Justificación y controles requeridos. |
| Revisar resultados | Examina el historial propio. | Una respuesta verificable y una limitación identificada. |

La actividad no se acredita solo porque una ejecución tenga estado exitoso: debes explicar qué extracto contractual sustenta cada afirmación publicada.
