# Workshop 2: RAG contractual con evidencia verificable

En este workshop usarás OCI Generative AI y Autonomous Database (ADB) para responder preguntas sobre contratos sintéticos versionados. El dashboard local muestra la respuesta, los criterios del ejercicio, las citas, los extractos y la traza de servicios reales.

## Empieza como participante

Sigue la [Guía única paso a paso del participante](docs/participant_step_by_step.md). Es el único recorrido que necesitas para ejecutar el workshop.

La guía incluye:

1. Descargar el repositorio mediante `git clone` o archivo ZIP.
2. Preparar Python 3.11 en Windows, macOS o Linux.
3. Crear el entorno virtual e instalar dependencias.
4. Cargar tu asignación privada y validar ADB.
5. Abrir el dashboard local.
6. Completar la ruta guiada de 180 minutos: preparar el corpus sintético autorizado, ejecutar casos OCI reales, revisar evidencia y justificar límites del sistema.

> **Importante:** recibirás identidad OCI, acceso a ADB, wallet y archivo de sesión por un canal privado. No están en este repositorio y no debes compartirlos, modificarlos ni subirlos a Git.

## Qué aprenderás

- Por qué una respuesta semánticamente cercana no puede sustituir un filtro explícito de versión.
- Cómo recuperar evidencia y asociarla a cada afirmación publicada.
- Cuándo solicitar una aclaración, abstenerse por evidencia insuficiente o recomendar datos estructurados.
- Cómo inspeccionar la latencia y las operaciones OCI que realmente ocurrieron.

## Límites de seguridad

Solo usa contratos y preguntas sintéticas. No ingreses datos de clientes, credenciales, tokens, wallets ni información personal en el dashboard, terminal o chat.

Cada solicitud pagada a OCI requiere una confirmación explícita en el dashboard. No hay respuestas preparadas ni un modo simulado que pueda acreditar la actividad.
